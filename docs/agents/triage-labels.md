# Etiquetas de triage

Los skills hablan de cinco roles canónicos de triage. Este fichero mapea esos roles
a las cadenas de etiqueta que usa el tracker de este repo.

| Rol canónico         | Etiqueta en este repo | Significado                                   |
| -------------------- | --------------------- | --------------------------------------------- |
| `needs-triage`       | `needs-triage`        | Falta que quien mantiene evalúe el issue      |
| `needs-info`         | `needs-info`          | Esperando más información de quien reporta    |
| `ready-for-agent`    | `ready-for-agent`     | Totalmente especificado, apto para un agente AFK |
| `ready-for-human`    | `ready-for-human`     | Requiere implementación humana                |
| `wontfix`            | `wontfix`             | No se va a atender                             |

Las cinco existen ya en el repo de GitHub. Las demás etiquetas del repo
(`bug`, `enhancement`, `documentation`, …) describen tipo de trabajo, no estado de
triage: no las uses como sustituto de estos roles.

Cuando un skill mencione un rol (por ejemplo "aplica la etiqueta de listo para
AFK"), usa la cadena correspondiente de esta tabla.
