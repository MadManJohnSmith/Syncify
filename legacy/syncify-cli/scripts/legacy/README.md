# Legacy Prototyping Scripts

This directory contains historical Python prototyping scripts from early Syncify migration and lyrics experiments:
- `dashboard.py`: CLI status dashboard prototype.
- `main.py`: Initial Python entry point harness.
- `redownload_lyrics.py`: Apple Music lyrics batch downloader.
- `start_migration.py`: Quick start Spotify -> Qobuz migration script.
- `force_redownload_lyrics.py`: Word-spacing lyrics fix harness.
- `run_migration.py`: Core Spotify to Qobuz migration engine.
- `test_lyrics_multi.py`: Multi-source lyrics resolution harness.

> [!NOTE]
> These scripts are preserved for historical reference and standalone CLI testing. They are not connected to the main Rust/Tauri build pipeline nor executed by the graphical application.
